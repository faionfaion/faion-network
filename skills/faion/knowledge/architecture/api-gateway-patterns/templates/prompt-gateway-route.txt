# purpose: Prompt for adding a gateway route without smuggling business logic into a plugin.
# consumes: resource name, upstream service + port, target gateway config file
# produces: a route + smoke-test change request that stays inside r6 (stateless gateway)
# depends-on: content/01-core-rules.xml
# token-budget-impact: ~150 tokens when loaded as context

Add /api/v2/<resource> → <service>-v2:8080 to kong.yml.
- Plugin: jwt (claim exp), rate-limiting (60/min/consumer, Redis), correlation-id
- strip_path: false. preserve_host: true.
- Add a healthcheck route /health/v2 returning 200 from the service
- Smoke test: scripts/gateway/smoke-<resource>.sh that calls /api/v2/<resource>
  with valid token (200) and invalid token (401)

Do NOT add request-transformer, response-transformer, or any business logic plugins.
Keep gateway boring — auth, rate-limit, route, trace only.
