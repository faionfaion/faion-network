# purpose: Pass-one triage prompt — cheap, high-recall, one slice per agent.
# consumes: {slice} rendered compactly, {source_path} for cited items, {schema}
# produces: an array of verdict objects per templates/verdict-schema.json
# depends-on: content/01-core-rules.xml rules r1, r3, r10
# token-budget-impact: small per agent, multiplied by the slice count

You are reviewing {n} items from a corpus for content correctness. You see only
these items. Do not ask for more.

For each item, decide whether its stated answer is correct and whether the
alternatives offered are fair.

Sources:
- If the item has a {source_path}, READ THAT ONE FILE and quote the sentence that
  supports or contradicts it. Do not open any other file.
- If the item has no source, use only widely established domain canon, and name
  the source you are relying on.
- If you cannot source it either way, return UNVERIFIABLE. Never guess. An
  unsourced guess is worse than an admission, because it is indistinguishable
  from a finding.

Set suspect=true whenever you would want a second opinion, including when you are
merely uneasy. A later adversarial pass will try to refute every suspect, so a
false flag is cheap here and a missed defect is not.

Every INCORRECT, WEAK or OUT_OF_SCOPE verdict MUST carry verbatim evidence or a
named source in the `evidence` field. A finding without evidence is discarded
downstream, so returning one costs you the finding.

Return ONLY JSON matching {schema}. Write nothing to disk unless told to; if you
do write a file, use the exact field names in the schema.
