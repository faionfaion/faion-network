# Context Graph Engineering

## Summary

**One-sentence:** Produces a Graph Design Record that first proves a graph is warranted at all, then constrains edge construction, traversal budget and integrity checks so the graph never costs more than the retrieval it replaces.

**One-paragraph:** Graph retrieval is sold as an upgrade over search. On the only shared benchmark it is not: flat retrieval with reranking beats graph retrieval on fact-shaped questions while costing 1/40th the query tokens, and graph-global search costs ~380x flat. Graphs earn their keep on a narrow band — multi-hop synthesis over data that genuinely has M:N structure, cross-branch links, cycles or temporal validity. This methodology makes that gate explicit and machine-checkable. Most honest records terminate at the gate with `warrant: none`, which is the correct and cheapest outcome. When a warrant does hold, seven rules keep construction derived rather than extracted, traversal bounded rather than open, and integrity gated in CI rather than assumed.

**Ефективно для:**

- Anyone about to adopt GraphRAG or a knowledge graph because it sounds like the mature choice.
- Retrieval that already costs graph-level tokens while delivering tree-level capability — the common silent case.
- Agent memory where facts expire and "was true" must be distinguishable from "is true".
- Code navigation over a repo large enough that grep-and-dump has stopped fitting the context window.

## Applies If (ALL must hold)

- A retrieval or agent-memory structure is being chosen or replaced.
- Query cost per lookup is measurable and someone is paying it.
- The corpus is large enough that dumping it whole is not an option.

## Skip If (ANY kills it)

- The corpus fits in the context window — structure is irrelevant, dump it.
- Retrieval is single-hop lookup by known identifier — a map wins.
- No one has measured the incumbent structure's cost per query yet; measure first, this methodology needs that number as input.

### `templates/graph-design-record.yaml`

```yaml
#
# Graph Design Record — proven-warrant case. See 02-output-contract.xml.
# If your warrant is `none`, do NOT edit this file — use
# graph-design-record-no-graph.yaml instead. A record that answers `none`
# and then specifies edge types has not understood the gate (r1).
#
# Validate:  validate-context-graph-engineering.py graph-design-record.yaml

system: "code navigation over a Go monorepo, ~400k LOC"

# --- The gate (r1) ---
warrant: cross_links          # m_to_n | cross_links | cycles | temporal
warrant_evidence: >
  Call sites cross package boundaries constantly; sampling 200 references,
  40% resolve outside their own subtree, so containment cannot express them.
rejected_alternative: tree

# --- Does it pay? (r2) Measured over the SAME ten real queries. ---
cost_incumbent_tokens: 30000
cost_graph_tokens: 4000

# --- Construction (r3, r4). Exactly one of derived_from / extracted_by each. ---
edge_types:
  - name: CALLS
    direction: outbound
    meaning: "caller invokes callee"
    derived_from: "tree-sitter call sites"
    temporal: false
  - name: IMPORTS
    direction: outbound
    meaning: "package depends on package"
    derived_from: "import statements"
    temporal: false
supernode_cap: 5000

# --- Traversal (r5). worst_case_nodes must equal sum(max_fanout^i, i=0..max_hops). ---
max_hops: 2
max_fanout: 8
worst_case_nodes: 73
context_budget_tokens: 20000
ranking_function: >
  personalized PageRank seeded on the files in the current diff,
  times edge weight, times recency decay

# --- Integrity (r7). All three checks, each wired to a failing CI job. ---
integrity_checks:
  - check: referential
    ci_job: "graph-integrity"
  - check: orphans
    ci_job: "graph-integrity"
  - check: acyclicity
    ci_job: "graph-integrity"
rebuild_trigger: "any merge to main; incremental re-index of changed packages only"
```

### `templates/graph-design-record-no-graph.yaml`

```yaml
#
# Graph Design Record — gate-stop case. See 02-output-contract.xml.
# This is the most common correct outcome and the whole record is four fields.
# Do not add graph design keys below; the validator rejects them (r1).
#
# Validate:  validate-context-graph-engineering.py graph-design-record-no-graph.yaml

system: "methodology retrieval over a 2,600-document knowledge corpus"

warrant: none
warrant_evidence: >
  Every lookup resolves to one domain and then one slug; no document has two
  parents, references do not jump between domains, and nothing expires. The
  four warrants were checked against the data, not assumed away.
rejected_alternative: tree

# Nothing else. The structure stays a hierarchy; spend the effort on making
# the index compact instead of on building edges nobody will traverse.
```
