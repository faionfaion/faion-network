# CR-005 — `{script}` is the tool-card invoke contract, not the fallback

- **Problem**: the five tool cards shipped with F029 (`skills/faion/tools/*/tools/*.card.md`) write their invoke line as `python3 scripts/foo.py …` / `sh scripts/venv-bootstrap.sh …`. That path is correct only inside this repo. A materialised pack lives at `~/.faion/tools/<pack>/<name>.py`, so an agent that pastes the card's line runs nothing, or worse, runs a same-named script that happens to sit under `./scripts/`. The CLI's `Card.ResolveInvoke` (faion-cli `internal/tools/card.go`) substitutes the materialised absolute path into the `{script}` placeholder; the corpus never wrote one, so every card resolved through the second branch — a fallback that rewrites *any token whose basename matches the script's filename* into the absolute path. The cards worked by accident of a compatibility shim, and the two sides of the contract disagreed about what a card is.

- **Change** (corpus side): all five cards now write `{script}` in `## Invoke` — `python3 {script} …`, `sh {script} …`, both lines of `hmac-rng-golden`. Every other section is byte-identical; the diff is 6 lines across 5 files. `skills/faion/tools/AGENTS.md` records the placeholder in the card-shape rule, so the next pack author writes it without reading the resolver.

- **Why the placeholder and not the fallback**: the fallback is token-matching over a command line — it cannot tell the script's own filename from an argument that happens to share it (`--out {name}.py`, a `--label` naming a module file), and it silently does nothing when a card renames the script. The placeholder states the substitution point explicitly, which is what makes the card a contract an agent can execute rather than a string the resolver has to guess at. The fallback stays useful as a compatibility shim for third-party or older packs; it is not the design, and no corpus card should depend on it again.

- **Evidence**: rebuilt the CLI against the real corpus (`make build SKILLS_DIR=…/faion-network/skills`), synced into a scratch config at tier `free` (python-web) and tier `geek` (game-dev, research), and read back all five cards: `faion tools card <name>` reports `invoke="… /…/.faion/tools/<pack>/<name>.(py|sh) …"` with the placeholder replaced and every argument placeholder (`{project}`, `{claims.jsonl}`, `{n}:{msg}`) preserved. No literal `scripts/` token remains in any invoke line.

- **Scope**: corpus-side only. `ResolveInvoke` keeps both branches — removing the fallback is a CLI decision and would break any card outside this repo.
